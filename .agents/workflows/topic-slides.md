# 教學型 HTML 簡報生成工作流（Graph + Local Loop）

本工作流將簡報製作拆解為 6 個明確節點，**每個節點的狀態都必須儲存為 `slides-output/` 下的實體檔案**，嚴禁跳關或一次直接生成最終 HTML。

## 流程總覽與退回路線（Graph）
`[1. 檢索 Wiki]` → `[覆蓋率關卡]` → `[2. 抽取證據卡]` → `[3. 教學大綱]` → **`[人工確認關卡]`** → `[4. 逐頁稿 + 忠實度 Loop]` → `[5. 渲染 HTML + 排版 Loop]` → `[6. 交件報告與入口首頁]`

---

## 各節點執行與檢查規格

### 節點 1：檢索 Wiki 與覆蓋率關卡（產出：`slides-output/sources.md`）
- **輸入**：`wiki/index.md`、`wiki/overview.md` 及相關的 `wiki/concepts/`、`wiki/syntheses/`。
- **任務**：列出所有與「演算法入門教學」相關的 Wiki 頁面路徑與核心重點，寫入 `slides-output/sources.md`。
- **剎車條件**：若相關的 Wiki 概念頁少於 **3 頁**，立即停止流程並回報「Wiki 資料不足，請先執行 ingest」，禁止硬湊內容。

### 節點 2：抽取證據卡（產出：`slides-output/cards/card-<概念名>.md`）
- **權限隔離（只能看、不能做）**：每次只讀取「單一 Wiki 頁面」，將該頁面的關鍵定義、生活化類比、複雜度數據與 `[來源: raw/... | 原始連結](URL)` 逐條抽成證據卡。**嚴禁混入該頁面以外的任何外部知識**。

### 節點 3：規劃 10 頁教學大綱（產出：`slides-output/outline.md`）
- **輸入**：`slides-output/cards/` 內所有證據卡。
- **任務**：規劃一份 **10 頁**、適合初學者的教學大綱（建議結構：封面 → 為什麼需要演算法 → 衡量效率的尺：時間複雜度 Big-O → 基礎搜尋與排序 → 分治法與遞迴 → 動態規劃核心思維 → 貪婪演算法 → 圖論基礎搜尋 BFS/DFS → 演算法策略選擇對照表 → 總結與學習路線）。每頁需標明預計引用的證據卡檔名。
- **【人工確認關卡】**：產出 `outline.md` 後，**必須暫停並請使用者確認大綱**。若使用者認為缺少子題或順序不佳，退回節點 1 補檢索或退回節點 3 修改大綱。

### 節點 4：撰寫逐頁稿 ＋ 忠實度與字數檢查小迴圈（產出：`slides-output/drafts/slide-01.md` ～ `slide-10.md`）
- **權限隔離**：撰寫第 $N$ 頁時，只能讀取 `outline.md` 的該頁規劃與對應的證據卡，禁止引用卡片以外的內容。
- **前置規格限制（把檢查往前移）**：
  1. 每頁投影片正文總字數**嚴格限制在 120 個中文字以內**（採條列式短句，避免文字牆導致後續 HTML 溢出）。
  2. 每頁底部必須包含 `來源出處：` 欄位，明確列出對應的 `wiki/` 頁面、`raw/` 本地檔案與原始文章 URL。
- **局部小迴圈（最多 3 輪）**：
  - 執行檢查腳本 `python scripts/check_slides.py --stage drafts` 驗證字數是否超標、出處路徑是否真實存在。
  - 若第 6 頁未通過，**只退回重修 `slide-06.md`**，其他已通過的頁面保持不動。

### 節點 5：渲染 HTML 簡報 ＋ 視覺溢出檢查小迴圈（產出：`slides-output/deck.html`）
- **權限隔離**：只能讀取已通過檢查的 `slides-output/drafts/slide-*.md`，**排版時禁止擅自改寫或增刪逐頁稿的知識內容**。
- **設計規格**：
  - 單一自包含（Self-contained）HTML 檔，無外部 CDN 依賴，確保 GitHub Pages 穩定開啟。
  - 採用「清爽教學卡片風」（16:9 固定視窗比例容器、米白底色、深墨文字、清晰的重點標記框與視覺化步驟流程圖），支援鍵盤 `←` / `→` 翻頁、底部進度條與右上角頁碼（`1 / 10`）。
  - 每頁投影片右下角固定顯示精簡的可點擊出處標籤（例如：`出處：raw/01-big-o.md（查看原文）`，超連結指向該原始文章 URL），避免過長網址撐破版面。
- **局部小迴圈與退回路線（最多 3 輪）**：
  - 檢查每頁投影片內容高度是否超出 16:9 容器（溢出檢查）。
  - 若發現某頁文字過多導致畫面溢出，**禁止縮小字體硬塞**，必須將該頁退回**節點 4（`drafts/`）**精簡文字後再重新渲染。

### 節點 6：交件報告與 GitHub Pages 入口首頁（產出：`slides-output/report.md` 與 `index.html`）
- **產生檢查報告（`slides-output/report.md`）**：彙整本次執行的檢索頁面數、各輪檢查通過紀錄（字數統計、出處路徑驗證結果、渲染溢出檢查結果）。
- **建立 GitHub Pages 入口首頁（`index.html`）**：在專案根目錄生成一個乾淨的導覽首頁 `index.html`，提供兩個主要入口卡片：
  1. 直接開啟 `slides-output/deck.html` 教學簡報。
  2. 內建簡易的 Markdown 閱讀器或目錄清單，讓瀏覽者能在網頁上直接點閱 `wiki/index.md`、`wiki/overview.md` 與所有 `concepts/`、`syntheses/` 頁面。
