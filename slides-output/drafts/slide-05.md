# 循序推進的基石：遞增法與原地優化

- **遞增哲學**：不積跬步無以至千里。一次只做一件事，循序納入元素並推進狀態。
- **經典運作**：單遍掃描累加求和 $O(n)$；雙層迴圈挑選最小值之選擇排序 $O(n^2)$。
- **空間節流**：原地對調（In-place）直接交換兩數，免除開闢多餘暫存空間。
- **設計取捨**：程式結構精簡且極致省空間 $O(1)$，唯複雜排序需結合進階結構。
